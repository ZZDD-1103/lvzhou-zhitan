## 交互检查

1. 保存记录后，“巡查记录”页面出现对应数据。
2. 刷新页面后，本地记录和任务勾选状态仍然存在。
3. CSV 可下载，中文字段在常用表格软件中正常显示。
4. 修改表单数据后，巡查报告中的地块、湿度、EC、温度和提示同步更新。
5. 上传图片后只显示本地预览，网络请求中不出现图片上传。
