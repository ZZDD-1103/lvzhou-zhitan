# 架构与数据边界

## 当前公开原型

当前版本由 `dist/index.html`、`dist/extra.css` 和 `dist/app.js` 组成：

- 地块数据和任务状态保存在浏览器 `localStorage`。
- 照片只在当前浏览器预览，不上传服务器。
- 水盐提示使用透明的演示阈值：湿度低于 22%、EC 高于 3.5 dS/m、最高温度达到 34℃时生成对应复查事项。
- CSV 和巡查报告在浏览器内生成。
- 页面不调用真实模型、传感器、RDS、Redis 或对象存储。

## 目标云端架构

```text
浏览器
  │
  ├── 地块、记录、任务接口 ── 后端服务 ── RDS
  │                                  └── Redis
  ├── 田间照片上传 ─────────────── 对象存储
  └── 分析请求 ── 知识库或模型服务 ── 人工确认 ── 任务记录

CodeArts：需求管理、代码仓库、测试、构建、流水线和部署
```

## 数据表建议

- `users`：用户与角色。
- `fields`：地块名称、面积、位置和作物阶段。
- `inspections`：湿度、EC、温度、照片地址、记录时间和记录人。
- `analysis_results`：输入摘要、规则或模型版本、判断依据和人工确认状态。
- `tasks`：复测、设备检查、负责人、截止时间和完成状态。
- `reports`：报告版本、生成时间和文件地址。

## 使用边界

系统输出属于巡查辅助信息，不直接替代农技处方。任何灌溉操作都应保留输入数据、判断依据、人工确认人和实际执行结果。
