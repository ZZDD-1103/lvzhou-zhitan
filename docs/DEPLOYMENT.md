# 部署说明

## 静态演示版

本项目没有第三方依赖和构建步骤。将 `dist` 目录作为静态网站根目录即可部署。

本地运行：

```powershell
python -m http.server 8000 --directory dist
```

浏览器访问 `http://127.0.0.1:8000`。

## 华为云目标部署

1. 在 CodeArts 建立需求、代码仓库和流水线。
2. 将静态前端部署到华为云静态托管或 Web 服务。
3. 创建后端服务，并通过环境变量配置数据库、缓存和对象存储连接。
4. 在 RDS 创建地块、巡查记录、任务和报告数据表。
5. 在 Redis 中保存会话、热点数据和异步任务状态，并设置过期时间。
6. 在对象存储中设置田间照片与报告目录，使用受控上传地址。
7. 在流水线中依次执行代码检查、测试、构建和部署。
8. 部署后运行测试用例，并保存流水线截图、版本号和演示地址。
