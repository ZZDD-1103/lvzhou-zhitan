# 绿洲棉智

面向阿拉尔及南疆棉田的水盐管理智能体演示项目，适用于第十一届华为 ICT 大赛中国创新赛赛题 1。

## Demo 功能

- 地块总览：风险概况、任务流程、节水指标
- 智能诊断：输入棉花生育期、土壤湿度、EC 和天气数据，可上传照片并生成诊断
- 灌溉方案：生成分时段管理建议
- 巡检任务：将 AI 建议转成可执行清单
- 管理报告：生成可下载的阶段报告

## 本地运行

```text
直接用浏览器打开 dist/index.html 即可运行。
```

## 参赛技术方案

正式版本计划接入华为云码道 CodeArts 代码智能体、RDS、Redis、对象存储，并部署到华为云环境。当前页面为可交互 Demo，数据为演示样例，生产使用前需由农技人员校准。
