# 绿洲智探

面向阿拉尔及南疆棉田的水盐巡查记录演示项目，适用于第十一届华为 ICT 大赛中国创新赛赛题 1。

## Demo 功能

- 地块总览：示例数据、待办事项和巡查流程
- 数据分析：输入棉花生育期、土壤湿度、EC 和天气数据，按演示阈值生成提示；照片仅作记录
- 灌溉方案：生成分时段管理建议
- 巡检任务：将复查建议转成可执行清单
- 巡查报告：生成可下载的阶段记录

## 本地运行

```text
直接用浏览器打开 dist/index.html 即可运行。
```

## 参赛技术方案

正式版本计划接入华为云码道 CodeArts 代码智能体、RDS、Redis、对象存储，并部署到华为云环境。当前页面为可交互 Demo，数据为演示样例，生产使用前需由农技人员校准。
