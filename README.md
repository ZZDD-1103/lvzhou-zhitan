# 绿洲智探

面向阿拉尔及南疆棉田的水盐巡查记录演示项目，适用于第十一届华为 ICT 大赛中国创新赛赛题 1。

- 在线 Demo：https://green-cotton-intel.sharpisle15.chatgpt.site
- 当前版本：静态交互原型
- 开源许可证：MIT

## 当前 Demo 功能

- 地块总览：示例数据、待办事项和巡查流程
- 数据分析：输入棉花生育期、土壤湿度、EC 和天气数据，按演示阈值生成提示
- 巡查记录：使用浏览器本地存储保存记录，并支持 CSV 导出
- 照片预览：照片只在当前浏览器预览，不上传服务器
- 巡检任务：保存任务勾选状态
- 巡查报告：根据当前输入动态生成可下载的阶段记录
- 项目说明：明确当前实现与华为云接入计划

## 本地运行

```powershell
python -m http.server 8000 --directory dist
```

打开 `http://127.0.0.1:8000`。项目不依赖 npm 包，也不需要构建步骤。

## 参赛技术方案

当前公开版本是静态交互 Demo，尚未接入真实模型、传感器、RDS 或 Redis。正式版本计划使用华为云码道 CodeArts 完成需求、编码、测试和部署流程，使用 RDS 保存地块与巡查记录，使用 Redis 管理会话和任务状态，并使用对象存储保存田间照片和报告。
